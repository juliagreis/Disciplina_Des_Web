Sobre a disciplina

Nesta disciplina, os alunos aprendem a criar páginas web utilizando HTML semântico, organizando corretamente o conteúdo e utilizando elementos adequados para cada tipo de informação.

Conteúdo da disciplina

  • Estrutura HTML
  • Introdução ao CSS
  • Introdução ao JavaScript
  • Programação em Elixir
  • Fundamentos do framework Phoenix
